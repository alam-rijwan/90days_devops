
# Linux Command Cheat Seat

## File System Commands

- `pwd`:-	Shows the current working directory.
- `ls` :-	Lists files and directories.
- `ls -la` :-	Lists all files, including hidden files, with details.
- `cd /path`:-	Changes the current directory.
- `mkdir folder`:-	Creates a new directory.
- `rmdir folder`:-	Removes an empty directory.
- `touch file.txt`:-	Creates a new empty file.
- `cat file.txt`:-	Displays the contents of a file.
- `less file.txt`:-	Views a file page by page.
- `head file.txt`:-	Displays the first lines of a file.
- `tail file.txt`:-	Displays the last lines of a file.

## Process Management Commands

- `ps`:-	Displays processes running in the current shell.
- `ps aux`:-	Displays all running processes with detailed information.
- `top`:-	Shows real-time CPU, memory, and process usage.
- `htop`:-	Interactive process monitoring tool.
- `pgrep nginx`:-	Finds the process ID of a process by name.
- `kill PID`:-	Terminates a process using its process ID.
- `kill -9 PID`:-	Forcefully terminates a process.


## Networking Troubleshooting Commands


- `ifconfig/ip a` :- Display all network interfaces with IP addresses.
- `netstat -a` :- Show listening tcp and udp ports and corresponding programs.
- `traceroute host` :- Traces network path.
- `wget url` :- Download files from internet.
- `whois domain` :- Displays whois information for domain.
- `host domain` :- Displays DNS IP address for domain.
- `nslookup domain`:- Display IP address of domain.


## Disk & System Information

- `df -h`:-	Shows available disk space in human-readable format.
- `du -sh folder/`:-	Shows the size of a directory.
- `free -h`:-	Displays RAM and swap memory usage.
- `uptime`:-	Shows system uptime and load average.
- `uname -a`:-	Displays Linux kernel and system information.
